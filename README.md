# ほめタマ (HomeHome) ✨
> 自己肯定感を高めるワンタップカウンター＆自分ほめメモアプリ

「ほめタマ」は、日々の小さな「できたこと」や自分への褒め言葉を簡単に記録し、自己肯定感を育むモバイルフレンドリーなWebアプリケーションです。

## 🌟 主な機能
1. **ワンタップカウンター**
   - 画面中央の大きなボタンをタップするだけで、心地よいサウンド・アニメーションと共に自己肯定感が高まるポジティブな言葉が表示されます。
   - 今日のタップ数、累計タップ数、継続ストリーク日数をリアルタイムで記録。
2. **マイルストーン＆バッジ解禁**
   - 累計タップ数に応じてレベルアップ！祝福の紙吹雪演出と共に新しいバッジや限定メッセージが解禁されます。
3. **自分ほめ・できたことメモ**
   - ワンタップで切り替えられるメモ機能。入力サポート用プロンプト（例：「今日できたこと」「嬉しかったこと」）やカテゴリ分けタグ、削除・フィルタリング機能を搭載。
4. **安心のデータ自動保存**
   - Web LocalStorage を利用し、カウント数やメモデータは端末内に安全に保持されます。

## 🛠️ 使用技術
- **HTML5** / **CSS3** (レスポンシブデザイン・グラスモフィズムアニメーション)
- **JavaScript (ES6+)**
- **Web Audio API** (タップ効果音・ファンファーレ合成)
- **HTML5 Canvas** (紙吹雪演出)

## 📱 使い方
1. リポジトリをクローンまたはダウンロードします。
2. `index.html` をブラウザで開くだけで、インストール不要で即座にご利用いただけます。
